# 002: Lot

## Representation

A quantity grid's spacing — the smallest meaningful quantity increment a
snapped value may land on. The `Quantity` counterpart to [Tick](001_tick.md),
same rationale: a single-field tuple struct so a validated, non-zero grid
spacing can't be confused with an arbitrary `Quantity`.
