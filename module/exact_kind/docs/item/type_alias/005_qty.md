# 005: Qty

## Representation

A non-negative quantity at a type-level scale, refusing construction whenever
its value would be negative. Ported from `exact_qty`'s
`Qty< const SCALE : u32 >` without behavioural change.

An alias of [`Amount`](../struct/001_amount.md) of the quantity kind,
[`QtyKind`](../struct/003_qty_kind.md): `Qty< SCALE >` is
`Amount< QtyKind, SCALE >`. Until
[ADR-006](../../decisions/006_one_amount_struct_generic_over_kind.md) it was a
struct of its own, holding one `Decimal< SCALE >` as a `value` field; its
members now read the same count with the private `value()` and build with
the private `from_value()`, and every path that builds a `Qty` still goes
through [`Qty::from_decimal`](../associated_function/010_from_decimal_qty.md)
(→ [ADR-001](../../decisions/001_non_negativity_enforced_at_construction.md)).
Its members are in [its own `impl` block](../implementation/005_qty_inherent_impl.md),
on `Amount< QtyKind, SCALE >` alone, so a `Qty` has no `MIN` and no
`checked_neg`; [`Quantity`](003_quantity.md) is the one at the standard scale.
