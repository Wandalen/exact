# 002: Qty

## Representation

A non-negative quantity at a type-level scale — a thin wrapper holding one
`Decimal< SCALE >` field, refusing construction whenever that decimal would
be negative. Ported from `exact_qty`'s `Qty< const SCALE : u32 >` without
behavioural change, now wrapping `exact_kind`'s own `Decimal` rather than a
separate crate's.
