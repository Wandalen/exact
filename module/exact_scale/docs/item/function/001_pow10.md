# 001: pow10

## Representation

`10ⁿ` as a backing value, for scales the backing width can hold. Panics past
`n = 18` — deliberate and reachable only from a `const` position, where it
becomes a compile error rather than a runtime one.

## Definition

`module/exact_scale/src/lib.rs:64`

```rust
pub const fn pow10( n : u32 ) -> i64
{
  assert!( n <= 18, "10^n exceeds the backing width for n > 18" );
  let mut out : i64 = 1;
  let mut i = 0;
  while i < n
  {
    out *= 10;
    i += 1;
  }
  out
}
```
